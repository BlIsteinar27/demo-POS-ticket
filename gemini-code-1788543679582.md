# Plan de Implementación: Gestión de Tasa de Cambio Dinámica (Opción B)

## 1. Visión General
Este documento detalla los cambios técnicos requeridos para integrar una tabla de configuración de tasa de cambio (`exchange_rates`) en Supabase y conectar su consumo con la PWA. El objetivo es que la app obtenga automáticamente la tasa del día para calcular los totales en VES y poblar los campos `tasa` y `tasa_day` en `sales` sin intervención manual en cada venta.

## 2. Base de Datos (Supabase SQL)
Ejecutar el siguiente script en el **SQL Editor** de Supabase para crear la tabla de tasas e insertar un registro inicial para hoy.

```sql
-- 1. Crear tabla de tasas de cambio
CREATE TABLE IF NOT EXISTS public.exchange_rates (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    rate NUMERIC(10, 2) NOT NULL CHECK (rate > 0),
    effective_date DATE NOT NULL UNIQUE DEFAULT CURRENT_DATE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 2. Habilitar RLS
ALTER TABLE public.exchange_rates ENABLE ROW LEVEL SECURITY;

-- 3. Políticas de acceso (Lectura pública / Inserción pública para el MVP)
CREATE POLICY "Permitir lectura publica de tasas" 
    ON public.exchange_rates FOR SELECT USING (true);

CREATE POLICY "Permitir insercion de tasas" 
    ON public.exchange_rates FOR INSERT WITH CHECK (true);

-- 4. Insertar tasa inicial para el día de hoy
INSERT INTO public.exchange_rates (rate, effective_date)
VALUES (36.50, CURRENT_DATE)
ON CONFLICT (effective_date) DO NOTHING;
```

## 3. Server Actions (`src/app/actions/exchange-rate.ts`)
Crear este nuevo archivo para gestionar la lectura y registro de la tasa desde el servidor.

```typescript
"use server";

import { createClient } from "@/lib/supabase/server";

export async function getTodayRate(): Promise<number | null> {
  const supabase = await createClient();
  const today = new Date().toISOString().split("T")[0];

  const { data, error } = await supabase
    .from("exchange_rates")
    .select("rate")
    .eq("effective_date", today)
    .single();

  if (error || !data) {
    return null;
  }

  return Number(data.rate);
}

export async function setTodayRate(rate: number): Promise<boolean> {
  const supabase = await createClient();
  const today = new Date().toISOString().split("T")[0];

  const { error } = await supabase
    .from("exchange_rates")
    .insert({ rate, effective_date: today });

  return !error;
}
```

## 4. Cambios en la Interfaz Principal (`src/app/page.tsx`)

### Cambios Requeridos:
1. Eliminar la constante dura `MOCK_TASA`.
2. Agregar un `useEffect` al montar el componente para consultar `getTodayRate()`.
3. Si la tasa no existe (retorna `null`), mostrar un modal/diálogo bloqueante para que el usuario ingrese la tasa del día.
4. Usar la tasa obtenida de Supabase para calcular `totalVES` y armar el `SalePayload`.

### Snippet de Integración en React:

```tsx
// 1. Nuevos estados
const [tasa, setTasa] = useState<number | null>(null);
const [isRateModalOpen, setIsRateModalOpen] = useState<boolean>(false);
const [tempRate, setTempRate] = useState<string>("");

// 2. Carga inicial de la tasa
useEffect(() => {
  async function loadRate() {
    const currentRate = await getTodayRate();
    if (currentRate) {
      setTasa(currentRate);
    } else {
      setIsRateModalOpen(true); // Bloquea pantalla hasta ingresar tasa
    }
  }
  loadRate();
}, []);

// 3. Manejo de guardado de tasa manual
const handleSaveRate = async () => {
  const numRate = Number(tempRate);
  if (numRate > 0) {
    const success = await setTodayRate(numRate);
    if (success) {
      setTasa(numRate);
      setIsRateModalOpen(false);
    }
  }
};

// 4. Cálculo derivado usando la tasa de la BD
const totalVES = useMemo(() => {
  return tasa ? totalUSD * tasa : 0;
}, [totalUSD, tasa]);
```
